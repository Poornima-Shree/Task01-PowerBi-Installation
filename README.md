# Student Performance Analysis Using Python

## Project Overview
This project analyses student academic performance using Python and data science libraries. The main objective is to understand students' final Mathematics grades and explore how study time and gender relate to academic performance.

## Dataset Source
- **Dataset:** Student Performance
- **Source:** UCI Machine Learning Repository
- **Link:** https://archive.ics.uci.edu/dataset/320/student+performance
- **File used:** `student-mat.csv`
- **Records:** 395 students
- **Features:** 33 columns

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas – data loading and analysis
- NumPy – numerical operations
- Matplotlib – data visualization
- Seaborn – statistical visualization
- VS Code – development environment

## Project Steps

1. Installed Python and configured the development environment.
2. Installed the required Python libraries.
3. Downloaded the Student Performance dataset from UCI.
4. Loaded the dataset using Pandas.
5. Explored the dataset using `head()`, `info()` and `describe()`.
6. Checked for missing values.
7. Calculated the average final Mathematics grade.
8. Created charts to understand grade distribution and the relationship between study time and final grades.
9. Interpreted the results and documented the findings.

## Analysis and Visualizations

### 1. Distribution of Students' Final Grades
A histogram was created to understand how students' final Mathematics grades (`G3`) are distributed.

**Finding:** Most students' grades are concentrated around the middle of the grading scale, while fewer students achieved very high grades.

### 2. Study Time vs Average Final Grade
A bar chart was created to compare average final grades across different weekly study-time categories.

**Finding:** Students in the higher study-time categories generally show slightly higher average grades. However, the difference is not large enough to conclude that study time alone determines academic performance.

## Key Findings

- The dataset contains 395 student records and 33 features.
- The average final Mathematics grade (`G3`) is approximately **10.42 out of 20**.
- The final grade distribution shows differences in student academic performance.
- Average grades vary across weekly study-time categories.
- Data visualization makes it easier to identify patterns and communicate findings.
